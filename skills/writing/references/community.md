# 커뮤니티 게시글·댓글

질문·경험 공유·정보 전달·의견·답글 중 대화의 목적을 잡는다. 요청한 존댓말·반말과 게시판 규칙을 따르되 사이트 특유의 유행어·공격적인 말투를 추측해 붙이지 않는다.

- 질문은 상황, 이미 해본 일, 답을 받고 싶은 지점을 필요한 만큼 쓴다. 답을 유도하려고 실패 경험이나 조건을 만들지 않는다. 짧은 댓글은 상대 글의 구체적인 지점에 답하고 장문의 설명문으로 늘리지 않는다. 메모 중 답에 필요한 경험과 판단을 바꾸는 조건을 고른다. 질문과 무관한 장비·기능·모르는 사실까지 모두 열거하지 않되, 사용자가 명시한 필수 항목은 남긴다.
- 경험 공유는 사용자가 준 경험의 범위를 지킨다. 개인 사례를 보편적 효과로 바꾸거나 직접 써보지 않은 물건을 써본 것처럼 말하지 않는다. 추천·비교의 근거와 모르는 부분을 구별한다.
- 의견 글은 쟁점을 일찍 드러내고 이유·사례를 연결한다. 상대의 의도를 단정하거나 허구의 다수 의견·추천 수·댓글 반응을 근거로 만들지 않는다. 사용자가 원하는 단호함·유머는 살리되 논점을 조롱으로 대체하지 않는다.
- 제목은 실제 질문이나 경험을 드러낸다. 댓글을 유도하는 맺음말은 필요할 때만 쓰고 '여러분은 어떻게 생각하시나요?'를 매번 붙이지 않는다. 게시글 작성과 실제 게시를 구분한다.

## 작성자 연령대·성별과 말투

요청에 맞춰 작성자 프로필을 설정할 수 있다. 연령대는 10대·20대·30대·40대·50대·60대 이상처럼 구분하거나 구체적인 나이를 쓴다. 성별은 남성·여성·미지정 또는 사용자가 제시한 정체성을 따른다. 연령대와 성별만으로 글의 자연스러움이나 실제 집단을 대표하는 문체가 보장되는 것은 아니다.

- 프로필에는 필요에 따라 게시 장소, 글을 쓰는 목적, 해당 주제의 경험, 성격, 존댓말·반말, 문장 호흡, 이모지·유행어의 정도를 함께 반영한다. 명시된 말투와 제공 문체 표본이 연령·성별에 대한 막연한 예상보다 우선한다.
- '여성은 감성적·남성은 논리적', '10대는 줄임말·고령층은 훈계조' 같은 고정된 규칙으로 차이를 만들지 않는다. 지정한 성별만 다르고 경험·말투·상황이 같다면 문체가 비슷할 수 있다. 나이나 성별이 드러나도록 억지로 표지를 넣을 필요는 없다.
- 연령·성별에서 자녀·배우자·직업·은퇴·디지털 숙련도·건강·주거 형태 등을 추정해 경험담에 보태지 않는다. 실제 경험 기반 글은 제공 메모의 사건·조건을 유지한다. 허구의 프로필과 경험을 창작해 달라는 요청이면 그 허용 범위에서 설정할 수 있다.
- 여러 버전을 요청하면 같은 사실을 유지하며 지정한 프로필과 말투에 맞게 어휘·문장 길이·정보 순서·유머를 조절한다. 비교용 연령·성별 표시는 게시글 밖에 두고, 글 안에서 자기 나이·성별을 소개하는 것은 요청이나 글의 목적에 필요할 때로 한정한다.
- 개인별 목소리의 차이를 뚜렷하게 요청하면 말끝·문장 길이 외에 각 작성자가 무엇을 중심으로 보고 어떤 질문이나 판단을 전하려는지 정한다. 같은 세부를 같은 순서로 모두 나열한 뒤 말투만 바꾸기보다, 각 관점에 필요한 정보의 비중과 연결을 달리한다. 이때 이해에 필요한 사건·조건과 사용자가 지정한 핵심은 남기고, 차이를 만들려고 메모에 없는 경험·감정·선호를 보태지 않는다. 관점 설정과 사실 보존을 함께 확인한다.
- 프로필을 주지 않은 단일 글은 임의의 연령·성별을 사실로 설정하거나 불필요하게 되묻지 않는다. 기존 글의 최소 교정에서는 프로필이 추가됐다는 이유로 말투까지 바꾸지 않는다. 글만 보고 실제 작성자의 연령·성별을 맞혔다고 하지 않는다.

## 긴 경험 공유의 정보 진전

초안 뒤 각 문단이 새로 보여 주는 관찰·행동·질문의 변화가 무엇인지 살핀다. 앞서 밝힌 ‘아직 모른다·확인하지 않았다’를 다시 증명하는 문단은 그 한계가 판단을 바꾸는 위치에 합친다. 같은 감상이나 미완료 상태를 각 단계의 새 성과처럼 반복하지 않는다. 필요한 미확인은 남기되, 한계 목록보다 실제 경험의 변화를 따라 읽히게 한다.

반복을 덜어낸 뒤 요청 분량과 제공 사실을 다시 대조한다. 하한을 채우려고 같은 설명이나 새 경험을 보태지 않는다. 자료 자체가 부족하면 [자료량과 분량의 충돌](everyday.md#자료량과-분량이-충돌할-때)을 처리한다. 이 점검은 문단을 합치기 위한 기준이며 모든 문단에 새 사건·극적 변화·별도 교훈을 요구하지 않는다.
