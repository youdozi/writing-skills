# 독립 AI 검토

별도 세션을 사용할 수 있고 위임이 허용된 경우 적용한다. 원래 요청, 대상 장르·독자·분량·말투, 원자료 또는 이전 장면과 설정, 출력 및 관련 스킬 지침을 전달한다. 최초 검토에는 작성자의 판정·예상 오류·정답을 주지 않는다.

검토자는 먼저 글 자체를 읽어 흐름·목소리·리듬을 살피고, 원자료와 요청을 대조한다.

자연스러움 검토에서는 말투의 일관성, 글을 쓰는 상황에 맞는 정보 선택, 내용 없는 반복·상투적인 도입/결론, 독자가 이미 아는 뜻의 재설명을 구체적인 대목으로 짚는다. 격식·의도한 반복·문학적 여백을 결함으로 일괄 판정하지 않는다. 선택적인 취향 제안과 사실·조건·약속·요청 위반을 나누고 AI 작성 여부나 실제 독자의 선호를 판별했다고 하지 않는다.

독자의 이해를 확인해 달라는 요청에는, 가능하면 원고 한 편만 받는 별도 읽기 역할을 둔다. 출처 본문·작성 의도·전달 목표를 미리 주지 않고 핵심과 인과관계를 자기 말로 설명하게 하며, 본문 근거와 남은 질문을 받는다. 응답을 보존한 뒤 원래 요청·자료·전달 목표와 대조해 누락·오해·사전지식 보충을 구별한다. 모든 세부 설명을 더할 필요는 없고, 글의 목적에 필요한 연결이 빠졌을 때 해당 부분을 고친다. 이 방식도 AI의 사전지식을 배제하거나 실제 독자의 이해도·흥미를 입증하지는 않는다. 일반 글 작성과 최소 교정에 이 절차를 의무화하지 않는다.

장르별로 다음을 본다.

- 교양 해설·비평: 개념·기작·계산과 전제의 정확성, 출처가 지원하는 범위, 관찰·해석·가상 예시의 구별, 독자에게 약속한 질문의 해소. 흥미와 이해 흐름은 구체적인 위치·연결에 근거하며 실제 독자 반응으로 포장하지 않는다.
- 개발 프로젝트 고객 커뮤니케이션: 고객이 판단할 영향·요청이 분명한지, 확인된 사실/추정·제안/승인·예상/확정·복구/검증이 구별되는지 확인한다. 새 비용·기한·보장·책임 결론을 임의 약속하지 않고 원래 채널·수정 범위를 지키는지 본다.
- 시사: 출처가 실제 주장을 뒷받침하는지, 시점·계획 상태·사실과 의견의 구별.
- 커뮤니티: 대화 목적·말투·게시 규칙, 개인 경험과 일반화의 경계.
- 일상: 팩트 기반은 제공된 생활 사실과 감정의 강도, 픽션 기반은 허용된 설정·시점·사건의 일관성을 확인한다. 두 경우 모두 요청 밖의 감정 과장이나 강요된 교훈이 없는지 살핀다.
- 소설: 시점·설정·인과관계·장면의 진행, 요청한 서사 형식. 새로 창작한 허구 자체는 오류가 아니다.

프랑스어는 [문장 교정](french-editing.md) 지침으로 술어의 문형·대명형·일치 형태를 따로 대조한다. 자연스러운 흐름만 보고 문법 검토를 대신하지 않는다.

러시아어 문법을 별도로 검토·교정할 때는 [최소 문법 교정](russian-proofreading.md)으로 실제 오류와 원문 대비 변경 범위를 대조한다.

정확성·설정·요청 불이행 문제와 선택적인 취향 제안을 구분한다. 위치·짧은 인용·이유·수정안을 남기고, 원자료가 부족해 판정할 수 없는 부분은 미확인으로 기록한다. 짧다는 이유만으로 좋은 글이라고 하거나 모호함·반복을 일률적으로 삭제하라고 하지 않는다.

작성자가 근거를 확인해 수정하고 보통 재확인 한 번으로 마무리한다. 중요한 새 문제가 있을 때만 추가한다. 별도 평가에서는 대상 해시·최초 지적·수정·재확인·실제 검사와 미검증 범위를 남긴다. 같은 모델의 별도 세션 검토를 사람·원어민·여러 모델의 합의로 표현하지 않는다. 일반 글 결과물마다 검토표를 붙일 필요는 없다.

## 스킬 개선을 위한 별도 평가

일반 원고 작성마다 이 절차를 요구하지 않는다. 스킬의 효과를 비교하는 작업이면 실제 사용 자료·공개 자료·합성을 구별하고, 개선에 사용할 문항과 이번 변경에 사용하지 않을 평가 문항·판정 기준을 생성 전에 고정한다. 평가 결과를 보고 규칙을 고치는 데 쓴 문항은 이후 개발/회귀용으로 분류하고 새 평가 문항과 구별한다. 제공되지 않은 실고객 자료나 독자 반응이 있다고 가정하지 않는다.

같은 요청을 반복해 편차를 볼 때는 가능한 한 조건을 맞춘 분리된 작성 맥락을 사용하고 최초 원고를 모두 보존한다. 반복 실행 수와 서로 다른 문항 수를 따로 적고, 같은 문안·동률도 남긴다. 버전 비교인지 같은 버전의 실행 편차 비교인지 명시한다. 원하는 선호가 나올 때까지 재생성하거나 좋은 원고만 선택해 비교하지 않는다.

익명 비교의 선호와 사실·조건 위반은 따로 집계한다. 본문만 읽은 역할의 질문이 모두 원고 결함인 것은 아니다. 글의 목적에 필요한 공백인지 원자료와 대조하고, 정보가 빠진 원자료를 보완한 것과 스킬을 수정한 것을 구별한다. 지침이 늘었거나 검사에 통과했다는 사실을 품질 향상의 증거로 삼지 않는다.

리뷰 자체를 평가할 때는 정상본과 의도적으로 조건·수치·부정·보호 문장을 바꾼 원고를 섞고, 최초 검토자에게 정답과 변형 위치를 주지 않는다. 오류를 놓친 경우와 정상본에 필수 수정을 요구한 경우를 따로 집계한다. 선택적인 문체 제안은 사실 오류 지적과 구별하며, 의도된 결함을 실제 사용자 원고에서 발견한 결함으로 보고하지 않는다.
