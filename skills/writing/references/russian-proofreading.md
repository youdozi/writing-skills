# 러시아어 문법 교정

러시아어 초안이 완성된 뒤 문법만 교정하거나 문장을 별도로 검토할 때 적용한다. 새 초안의 구성·어휘를 이 절차에 맞춰 다시 쓰도록 요구하지 않는다.

원문을 기준으로 실제 문법 오류의 위치와 근거를 먼저 내부적으로 확인한다. 술어의 격 지배, 생략된 명사의 수량 표현, 성·수 일치, 동사의 상·시제를 해당 문장의 의도와 대조한다. 의문이 남는 구문만 권위 있는 사전·문법 자료와 문맥으로 확인한다.

확인된 오류는 필요한 어미·단어·구문 범위만 고친다. 각 변경이 어떤 오류를 해결하는지 원문과 대조하고, 근거가 취향뿐이면 문법 교정본에 적용하지 않는다. 올바른 문장은 그대로 둔다. 구어체·의도적인 생략·리듬, 존칭·대명사, 감정·불확실성·수치·사건의 순서를 유지한다. 인물의 비표준 말투는 일관된 문맥이 있는지 보고 구분한다.

수정 뒤 문장만 읽는 단계와 원문과 바뀐 부분을 비교하는 단계를 나눈다. 새로운 격식체 표현, 경험 범위를 재차 설명하는 문장, 같은 뜻의 반복이 늘지 않았는지 확인한다. 문법만 요청받았을 때 선택적인 유창성 제안은 적용하지 않고, 요청한 출력 형식 안에서 필요한 교정만 전달한다. 새 의미를 정해야만 고칠 수 있으면 원문이 허용하는 범위를 보존하거나 필요한 모호함을 짧게 알린다.

별도 평가에서는 원문·교정본·변경 근거를 보관한다. 오류가 없으면 무수정도 올바른 결과다. 이 절차가 모든 러시아어 글의 정확성을 보장한다고 주장하지 않는다.
