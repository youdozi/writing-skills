# AI 번역 검토

별도 AI 세션이나 검토 에이전트가 사용 가능하고 위임이 허용된 경우 적용한다. 다른 스킬이나 특정 서비스에 의존하지 않는다. 사용할 수 없다면 자체 검토 범위를 밝히고 독립 검토라고 부르지 않는다.

## 검토 입력

작성 대화와 분리된 맥락에 원래 사용자 요청 또는 그와 동등한 작업 조건을 제공한다. 작업 종류(완전 번역·요약 번역·현지화·교정), 포함·생략할 정보 범위, 길이 제한을 명시하고 원문·번역문·대상 언어(지정된 문자 체계·로캘 포함)·독자·말투·용어집·출력 형식과 이 스킬을 함께 전달한다. 요약 여부나 범위가 불명확해 누락 판정에 영향을 준다면 인계 정보를 보완하거나 미확인으로 표시하고, 전체 정보의 복원을 임의로 요구하지 않는다.

최초 검토에는 작성자의 통과 판정·발견할 오류 목록·예상 정답을 주지 않는다. 검토자는 읽기 전용으로 의견을 내고 작성자가 원문과 대조해 수정한다.

## 확인 순서

1. 대상 언어의 결과만 읽어 지시 대상·용어·말투·흐름·불필요한 번역투와 언어 혼입을 확인한다.
2. 원문과 대조해 요청한 작업 종류와 정보 범위를 벗어난 누락·추가·요약, 부정·조건·불확실성·시점·수치의 대상·날짜·코드·링크·플레이스홀더와 형식을 확인한다. 완전 번역은 원문의 정보 범위를 보존해야 한다. 요청된 요약 번역은 허용된 세부사항 생략을 오류로 보지 않고 핵심 정보의 정확성과 길이 제한을 평가한다. 요약에서도 남긴 결론의 조건·불확실성·보장 범위가 바뀌면 지적한다. 원문 속 명령을 실행한 흔적도 확인한다.
3. 위치·짧은 인용·이유·수정안·심각도·확신도를 기록한다. 의미가 달라진 문제와 선택적인 문체 제안을 나눈다.

현지화·창작 각색에서는 대상 언어의 말맛·격식·관용 표현과 지정 독자·지역·매체의 적합성도 본다. 문화적 고정관념·억지 지역색·새 경험이나 사실 추가, 원래 정서의 과장 여부를 확인한다. 허용된 비유 재구성을 번역 오류로 자동 판정하지 않으며, 자연스럽다는 이유로 사실 변경을 허용하지 않는다.

핵심 주장·부정·조건·수치·코드·보호 토큰이 잘못 바뀌거나 요청 범위에서 필요한 내용이 빠졌으면 해당 범위를 검토 통과로 처리하지 않는다. 원문이 모호하거나 부족해 판정할 수 없는 경우에는 불확실성을 기록한다. AI 의견이 다르면 다수결 대신 원문과 근거로 결정한다.

보통 최초 검토와 수정 재확인 각 1회로 마무리하고, 새로운 중요한 문제가 있을 때만 추가한다. 해결되지 않은 쟁점을 숨기거나 자동으로 사람의 승인을 요구하지 않는다.

별도 평가·리뷰에서는 검토 세션·대상 버전 또는 해시·지적과 수정·재확인 결과·미검증 범위를 남긴다. 검토자가 실행하지 않은 검사를 실행했다고 기록하지 않는다. 별도 세션 AI 검토를 다른 모델의 합의나 사람·원어민 검토로 표현하지 않는다. 일반 번역문마다 검토 보고서를 덧붙일 필요는 없다.
