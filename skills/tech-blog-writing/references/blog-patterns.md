# 한국어·영어·일본어 기술 글에서 추출한 작성 기준

새 글의 구성·용어 설명·측정 결과 서술에 구체적인 참고가 필요할 때 관련 사례만 읽는다. 표의 '적용'은 원문에서 관찰한 장치를 바탕으로 한 이 스킬의 해석이다. 각 언어의 고정된 문화나 모든 기술적 주장이 옳다는 인증이 아니며, 문장을 복사하거나 사내 사례를 자신의 경험으로 사용하지 않는다. 과거 도구 사용법을 현재 튜토리얼에 사용할 때는 현행 공식 문서를 별도로 확인한다.

## 적용 범위

공통으로 반영한 내용은 검색 가능한 용어 보존, 실패 상황에서 해결책으로의 연결, 근거의 대상과 수준 구분, 개선되지 않은 결과·부작용 보존, 개발·운영 범위 유지다. 기존 스킬과 겹치는 원칙은 재사용하고, 새 목차나 필수 체크리스트를 글마다 추가하지 않는다. AI 검토에 활용할 때는 해당 사례와의 문체 유사도 대신 원문·사용자 자료에 대한 정확성을 평가한다.
