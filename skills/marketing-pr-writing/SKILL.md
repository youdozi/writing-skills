# 마케팅·PR 글쓰기

독자가 관심을 가질 이유와 판단에 필요한 근거를 자연스럽고 간결하게 전달한다. 전문가다운 글은 과장된 확신이 아니라 메시지의 선택·근거·맥락·관계를 잘 맞추는 글이다. 원고의 설득력을 실제 매출·전환·보도 성과로 인증하지 않는다.

## 목적과 작업 선택

기획·메시지 정리·원고 작성·기존 카피 퇴고·리뷰 중 요청한 결과물을 만든다. 제공 자료에서 조직/제품, 대상 독자, 해결할 관심사, 채널, 목표, 근거와 브랜드 말투를 파악한다. 마케팅은 인지·관심·행동 등 요청한 목표에, PR은 기자·이해관계자가 알아야 할 사실과 의미에 맞춘다. 보도자료·입장문을 판매 카피처럼 쓰거나 모든 문서에 구매 버튼을 넣지 않는다.

빠진 항목을 모두 묻지 않는다. 무엇을 누구에게 알릴지 판단할 수 없을 때만 핵심을 짧게 확인한다. 일부 수치·후기·가격·인용·연락처가 없으면 그 요소를 빼고 가능한 원고를 쓴다. 공개에 필수인 사실·승인 상태가 모호하면 해당 부분만 확인하거나 요청한 자리표시자/별도 확인 메모로 구별한다. 원고만 요청하면 내부 메모와 임시 사실을 독자용 문구에 섞지 않는다.

| 요청 | 필요한 지침 |
| --- | --- |
| 캠페인·광고·프로모션 이메일·SNS·메시지 후보 | [마케팅 원고](references/marketing.md) |
| 보도자료·언론 피치·공식 입장·미디어 Q&A | [PR 원고](references/public-relations.md) |

혼합 요청은 해당 부분만 함께 적용한다. 단순 문장 교정에 전체 전략·시장 조사·캠페인 설계를 강제하지 않는다.

## 메시지와 근거

제공하는 것과 독자의 관심·사용 상황을 연결하고, 그 연결을 뒷받침하는 사실을 필요한 곳에 둔다. 새로운 관점·구체적 장면·가벼운 기대 전환으로 흥미를 만들 수 있지만 클릭을 위해 본문이 제공하지 않는 답이나 혜택을 약속하지 않는다. 슬로건만 반복하거나 전문용어로 가치를 대신하지 않는다. 짧게 쓴다는 이유로 중요한 조건·감정·말투를 지우지 않는다.

- 확인된 사실, 제한된 관측, 추정/목표, 계획, 창작 시안을 구별한다. 예정된 출시에 ‘출시했다’, 협의 중 제휴에 ‘체결했다’처럼 상태를 강화하지 않는다. 기업·고객·발언자·제품·지역·시점·공개 범위를 보존한다.
- 없는 고객 후기·시장1위·수상·인증·추천·파트너·언론 반응·통계·재고·마감·할인·환경/건강/보안 효과를 만들지 않는다. 제공된 주장이라도 근거와 모순되거나 검증 범위를 넘으면 그대로 확정 사실로 키우지 않는다. 후기·비교·효과를 쓸 때는 대상·조건·기간과 수치의 분모/단위를 지킨다.
- 승인된 실제 인용과 제안용 발언 초안을 구별한다. 인용문 초안은 요청하면 작성할 수 있지만 실제 승인/발언된 것처럼 제시하지 않는다. 고정 인용문·수치·문구·출처를 보호하라는 요청은 그대로 지킨다. 가상 조직의 시안은 전달 맥락에서 허구임을 구별한다.
- 가격·무료 범위·대상·이용 기간·행사 조건과 행동 문구가 일치하게 쓴다. 상담/사전 알림 신청을 구매·계약·즉시 이용 확정으로 바꾸지 않는다. 실제 없는 전송 경로·자동 응답·후속 혜택을 추가하지 않는다.

참고 문구나 경쟁사 자료를 쓰면 실제 확인한 범위만 말하고 구성·메시지 선택을 참고한다. 고유 문구·경험·일화를 변형해 새 브랜드의 사실처럼 쓰지 않는다. 시장 현황·플랫폼 규격·규제·제도·시의성 있는 비교를 주장해야 하면 현재 공식/원출처를 확인한다. 단순 원고 작성에 불필요한 웹 조사를 매번 요구하지 않는다.

## 말투와 신뢰

요청한 브랜드의 말투와 채널을 따른다. 독자를 낮춰 보거나 타인의 실패·피해·불안을 이용해 주의를 끌지 않는다. 유머·위트는 메시지와 정서에 맞을 때만 쓰며 중요한 조건·사과·공식 입장의 의미를 흐리지 않는다. 과장된 긴박감·가짜 희소성·반복 사과나 감동을 억지로 넣지 않는다.

광고·협찬·대가성 관계가 주어지면 이를 독립 후기·자발적 추천처럼 위장하지 않는다. 실제 지역·매체·업종에 필요한 표시/정책 문구는 해당 조건과 최신 자료를 확인해야 하며 일반 카피만으로 준수·적법성을 인증하지 않는다. 정보가 부족하다는 이유로 모든 원고에 임의 법적 고지나 승인 절차를 붙이지 않는다.

요청한 다른 언어·지역·격식에 맞게 새 카피를 작성할 수 있다. 관용 표현·말맛은 조정하되 가격·지역·혜택·출시·승인 상태를 임의 현지화하지 않는다. 언어로 국적·취향·협상 문화를 단정하지 않는다. 원문 번역·대조만 요청하면 사용 가능한 translate가 적합하다. 새 언어의 광고 성과나 원어민 품질을 검증한 것으로 말하지 않는다.

## 검토와 전달

원고만 먼저 읽어 무엇을 왜 알리는지, 독자에게 어떤 의미가 있는지, 필요한 다음 행동이 무엇인지 확인한다. 그 뒤 원자료와 대조해 수치·조건·확정 수준·인용/공개 승인·제공 범위·행동의 약속을 점검한다. 제목·본문·이메일 제목·버튼 등 여러 산출물이 서로 다른 사실을 말하지 않는지 본다. 실제 오류와 선택적인 취향 제안을 구별한다. 복잡한 원고나 별도 리뷰 요청에서 위임이 허용되면 원래 요청·자료·원고를 분리된 검토자에게 주고 최초 판정·수정·재확인을 나눈다.

기본 출력은 요청한 원고다. A/B 후보·전략표·뉴스 가치 분석·검토표·해시태그·미디어 목록·성과 보고서를 자동으로 붙이지 않는다. 기획을 요청하면 독자·메시지·근거·채널·행동의 연결을 설명하고, 일부 퇴고는 보호 영역·키·변수·길이와 반환 형식을 지킨다. 실제 게시·메일 발송·기자 연락·광고 집행·성과 수집은 원고 작성과 별도 명시적 지시가 있어야 한다.

홈페이지 전체의 영역별 카피는 사용 가능한 website-copywriting, 관리자 UI는 cms-ux-writing, 개발 프로젝트 고객 협의문은 writing이 적합하다. 다른 스킬·특정 광고/배포 서비스가 이 스킬의 필수 의존성은 아니다. 연결되지 않은 도구를 사용했거나 외부에 배포했다고 주장하지 않는다.
