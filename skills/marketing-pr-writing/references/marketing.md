# 마케팅 원고

필요한 작업만 적용한다. 모든 요청을 같은 관심→불안→해결→구매 공식으로 채우지 않는다.

## 메시지 선택과 캠페인

고객이 실제로 하려는 일과 제품의 확인된 기능을 연결한다. 기능을 이익으로 설명하되 기능에 없는 성과를 보장하지 않는다. 독자의 문제를 제공 자료보다 심각하게 만들거나 ‘아직도 이것도 모르나요’처럼 면박을 주지 않는다. 핵심 메시지와 구체적 근거를 먼저 고르고 채널에 맞춰 정보량을 조절한다.

브랜드 메시지·포지셔닝 요청이면 대상, 해결할 일, 다른 선택지와의 차이, 그 차이를 말할 근거를 연결한다. 내부 희망·비전을 이미 입증된 시장 평가로 바꾸지 않는다. 근거가 없는 경쟁사 열위·국내최초·최고 같은 지위를 만들어 비교하지 않는다.

캠페인 기획을 요청하면 목적·대상·메시지·근거·채널·행동의 관계를 제시한다. 모집·구매·재이용·행사 참여 등 요청 목적에 맞게 쓰고, 없는 세그먼트 데이터·예산·일정·매체 성과를 발명하지 않는다. 성과 지표는 제안과 실측을 나눠 쓴다.

## 광고·짧은 카피

제목과 본문은 같은 약속을 한다. 짧은 제목에 세부를 모두 넣을 필요는 없지만 결론을 바꾸는 대상·조건은 함께 읽는 본문에서 알아볼 수 있어야 한다. 이용이 가능한 것과 신청을 받는 것, 무료와 일부 무료, 할인 전제와 실제 청구액을 구별한다. 매체의 글자 수/표기 조건이 주어지면 따르고 규격을 확인하지 않았으면 심사 통과·한 줄 노출을 보장하지 않는다.

A/B 후보 요청이면 무엇을 바꿔 비교하는지 목적에 맞춰 정하고 같은 사실·혜택·조건을 유지한다. 다른 사실이나 강한 허위 약속으로 차이를 만들지 않는다. 후보의 예상 효과는 검증할 가설이며 승자·전환 상승을 실측한 것처럼 쓰지 않는다. 두 후보를 요청했다고 실제 실험을 집행하지 않는다.

## 이메일·SNS·행사

프로모션 이메일은 제목·프리헤더·본문·행동이 같은 내용을 전달하게 쓴다. 요청한 요소만 제공하고 클릭을 유도하려고 실제 없는 배송/결제/보안 알림이나 개인적 연락처럼 위장하지 않는다. 메일을 써달라는 요청은 실제 수신 동의·전송·목록 수집 권한을 부여하지 않는다.

SNS·카드뉴스는 해당 게시물만 읽어도 핵심과 조건이 통하게 구성한다. 여러 장이면 각 장의 역할과 정보 흐름을 나누되 자동으로 과장된 첫 장·해시태그·댓글 유도·밈을 붙이지 않는다. 이해관계 표시를 요청 형식에서 알아볼 수 있게 유지한다. 행사·모집 안내는 실제 일시·장소·시간대·대상·신청 방식·비용·정원이 있는 범위에서 쓰고 임의로 ‘선착순/마감 임박’을 만들지 않는다.

출처가 제한된 성과나 후기의 조건은 해당 주장 가까이에 둔다. 일반화가 불가능한 자료로 모든 고객이 얻는 결과를 단정하지 않는다. 자료가 없어도 제공 가치와 실제 사용 과정을 중심으로 설득할 수 있다.
