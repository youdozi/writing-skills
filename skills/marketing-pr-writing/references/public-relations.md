# PR 원고

기자·이해관계자가 무엇이 새롭고 어떤 사실·영향이 확인됐는지 판단하도록 쓴다. 뉴스 가치와 조직이 바라는 평판을 구별한다.

## 보도자료와 발표

제목·리드에는 발표 대상·핵심 변화·확정된 시점을 사실 범위에서 담는다. 본문은 필요한 배경·구체적 제공 내용·근거·독자 영향으로 이어가고 과장된 찬사로 사실을 대신하지 않는다. 모든 발표를 ‘혁신/선도/최초’로 포장하지 않는다. 출시·시험 운영·사전 신청·계획·협약·계약 체결 등 실제 상태를 유지한다.

배포일·지역·발표 주체·일정·가격·연락처·회사 소개는 제공된 범위만 쓴다. 연락처가 없으면 발명하지 않는다. 아직 승인되지 않은 발표나 인용은 요청한 내부 검토용 시안으로 구별한다. 완성 원고만 요청했더라도 공개를 막는 핵심 미확인 사실은 숨기지 말고 필요한 확인/별도 메모를 처리한다. 자료가 부족하다는 이유로 모든 보도자료를 긴 빈칸 양식으로 반환하지 않는다.

승인된 인용문은 고정 요청대로 보존한다. 발언 초안을 요청받으면 초안임을 명확히 구별하고 발언자의 실제 경험·의견·승인을 대신 확정하지 않는다. ‘관계자는 밝혔다’라는 틀만으로 가상 발언을 실제 인용으로 만들지 않는다. 조직 소개 문구도 없는 설립연도·인원·실적·투자·인증을 채우지 않는다.

공개 시점·엠바고·비공개 범위가 주어지면 초안/배포본의 구분에 반영한다. 내부 메모를 공개 문구로 그대로 옮기거나 특정 기자가 엠바고에 동의했다고 만들어 쓰지 않는다. 실제 배포·기자 전송은 별도 지시 범위다.

## 언론 피치와 미디어 Q&A

피치는 해당 매체/기자의 관심사를 실제 확인한 범위에서 연결하고, 어떤 취재거리가 있으며 어떤 자료·인터뷰가 실제 가능한지 짧게 제시한다. 없는 최근 기사·인연·독점 제공·인터뷰 승낙을 발명하지 않는다. 보도자료 전체를 이메일에 되풀이할 필요는 없다. 보도 확정이나 응답을 약속하지 않는다.

Q&A는 질문의 우려에 직접 답한다. 핵심 질문을 다른 홍보 구호로 덮지 않고 공개 가능한 사실·현재 조치·미확인 범위·다음 공유를 구별한다. 내부 대응안·법적 검토·고객 신원을 불필요하게 노출하지 않는다. 답이 미확정이면 숨기기 위한 상투어보다 무엇을 확인 중인지 필요한 범위로 설명한다. 제공되지 않은 책임·보상·규제 판단을 새로 확정하지 않는다.

## 공식 입장·정정·위기 초기 대응

독자가 겪는 영향과 우려를 확인된 범위에서 인정한다. 현재 사실·조치·다음 안내를 먼저 제시하고 확인되지 않은 원인을 단정하거나 비난할 대상을 만들지 않는다. 원인 규명 전 ‘외부 탓’, 일부 복구 뒤 ‘모든 문제 해결’, 조사 중 ‘데이터 영향 없음’을 선언하지 않는다. 적절한 사과는 가능하지만 사과 반복으로 핵심을 대체하지 않는다.

정정문은 잘못된 사실과 바로잡는 사실이 구별되게 쓴다. 제공된 피해·영향·오류를 축소하지 않고, 범위를 넘는 법적 책임·보상 약속을 임의 추가하지 않는다. 발표 예정인 다음 업데이트가 있으면 유지하되 확인되지 않은 복구 시각·재발 방지 효과를 약속하지 않는다. 신뢰 회복의 목표를 달성한 것으로 보고하지 않는다.

모든 PR 요청에 위기 대응 절차나 법적 승인을 강제하지 않는다. 공개 문구의 확정 수준과 실제로 받은 승인 상태를 정확히 전달하는 것이 기준이다.
